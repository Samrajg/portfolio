Security Rounds Digital Verifier & Audit Trail

Real-time enterprise checkpoint verification and tamper-proof security auditing for factory facilities.

1. The Problem

Industrial textile plants rely on security personnel conducting regular night patrols across vast factory perimeters. Physical paper logbooks were frequently backfilled, easily manipulated, and left supervisors with zero real-time visibility during critical incidents.

2. The Approach

4. Outcome & Results

Successfully deployed into active commercial production at Pentagon Textiles (apps.pentagontextiles.com). Query optimizations cut API round-trip latency by 35% and completely eliminated manual paper registers.

TreeToCLI — Directory Tree AST Shell Generator

Converts ASCII folder diagrams directly into executable Bash, PowerShell, and CMD commands.

1. The Problem

README documentation frequently represents project file structures as plain ASCII trees, forcing developers to manually recreate dozens of folders and files one-by-one across different shell environments.

2. The Approach

Developed a zero-dependency, in-browser parser that interprets nested ASCII trees into an abstract syntax tree and generates ready-to-run setup scripts with a single click.

3. Implementation Details

Authored a recursive depth-tracking parser in pure vanilla JavaScript, handling indentation quirks, file extensions, and multi-OS command formatting without sending data to any external server.

4. Outcome & Results

Hosted live on GitHub Pages; generates scripts with sub-millisecond latency, zero maintenance overhead, and complete privacy for users.
